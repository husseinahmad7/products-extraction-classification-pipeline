# Dashboard implementation brief

Mode: Operate. Scope: dashboard/src/App.tsx, dashboard/src/styles.css.
The approved evidence-lifecycle wireframe pins navigation and workflow. This session
implements it directly; no standing workflow preference was inferred or stored.

## Direction contract

THESIS: Follow a dataset from source to evidence to decision; avoid a dashboard of
decorative metrics. Actual saved records and outstanding decisions are the content.

OWN-WORLD: Evidence docket: ink-blue navigation, cool pale working surface, white
document area, violet selection, compact system UI type and table rules. Monospace
is reserved for machine identifiers and code.

STORY: Connect, configure a source and target, validate an explicit recipe, approve,
run, inspect field evidence, then compare and publish. Empty, unsupported, queued,
failed and uncalibrated states remain distinct.

FIRST VIEWPORT: Fixed-width lifecycle navigation at left; titled work area, list and
selected evidence detail to the right. Primary action stays next to the relevant
list. On phones, navigation wraps and detail stacks below the list. The signature
interaction is selecting a record field to reveal raw values, locator, transforms
and immutable capture hash. Motion is a short selection transition with a
reduced-motion fallback.

FORM: Third grounded candidate, evidence docket, seed e4cfed72, translated through
the already approved lifecycle layout. Alternatives considered: lab log, diff
workbench, evidence docket, operations schedule, relational explorer, deployment
queue, data workbook. The approved brief outranks unchosen visual directions.
The roll's oscilloscopes, cracktro, hardware console, generative identity, cloth and
cloud forms were declined for this task: signal controls, drifting text, knobs,
reseeding, cloth and spectra obscure record-level audit. Their useful disciplines
are measurement precision, clear priority, decisive commit states, consistent tokens,
explicit transitions and visible uncertainty, not their decorative motifs.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

No raster imagery is needed by this operational surface. Browser verification and
finish-review status must be recorded honestly.
